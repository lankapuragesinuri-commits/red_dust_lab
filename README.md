# RED DUST LAB — starter research website

A responsive, multi-section static website for documenting an independent Earth-based experimental study of dust coverage and photovoltaic performance.

## Files
- `index.html` — page structure and editable research content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and conceptual coverage explorer

## Run locally
Open `index.html` in a modern browser. For local development, you can also use VS Code Live Server.

## Before publishing
1. Replace every `[bracketed placeholder]` with verified project details.
2. Add your actual dust-analogue composition and ratios from your approved preparation record. Do not estimate them.
3. Add the exact SOP version/date and link to the document.
4. Add actual experimental measurements only after collection and checking.
5. Replace the pending results panels with real data, graphs, trial counts and uncertainty.
6. Add complete citations for all scientific claims and image credits.
7. Check that any images used externally are permitted for your intended publication and retain required attribution.

## Scientific integrity
- The coverage explorer is explicitly conceptual. It does not calculate photovoltaic output.
- No sample experimental results have been invented.
- The project is described as an Earth-based analogue, not a direct reproduction of Mars.
- The site does not claim to be operated or endorsed by NASA.
- The remote hero/card photographs are illustrative placeholders. Replace them with properly licensed, credited project/NASA/public-domain imagery before public release.
